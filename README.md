# My Portfolio

A dark, glassmorphism-inspired portfolio with smooth animations and a responsive layout, built with a focus on performance and accessibility.

---

## Tech Stack

- **Framework:** Next.js
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Typography:** Poppins (via Next Font)

---

## Features

- Responsive layout optimized for desktop, tablet, and mobile.
- Glassmorphism UI with frosted glass cards, gradients, and layered depth.
- Smooth page transitions, scroll animations, and micro-interactions with Framer Motion.
- Reusable components and design tokens for consistent styling.
